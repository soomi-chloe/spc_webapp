# 🏭 공정능력분석 & 통계적공정관리 웹앱

> **Process Capability Analysis (PCA) & Statistical Process Control (SPC)**
> 스마트제조 강의 내용을 기반으로, 데이터 입력 → 실시간 공정능력 분석 → 관리도 작성 → 종합 대시보드까지
> 한 번에 수행할 수 있는 **Streamlit** 기반 통합 분석 도구입니다.

---

## 📌 주요 특징

- **반응형 분석**: 사이드바에서 데이터/파라미터를 수정하면 모든 차트와 지수가 자동으로 재계산됩니다.
- **시뮬레이션 + 업로드 지원**: 시뮬레이션 데이터 생성, CSV 업로드 두 가지 입력 방식을 지원합니다.
- **교육적 시각화**: Plotly 기반 인터랙티브 차트 + KPI 카드 + 신호등(🟢🟡🔴) 상태 표시.
- **이론과 코드의 일관성**: 강의 자료(`codesplus.md`)의 분석 로직(c4, d2, d3, A2, B3, B4, D3, D4 등 불편화 상수)을 충실히 반영했습니다.
- **이상점 탐지 & 재작성**: 관리도에서 이탈점을 자동 탐지하고, 제거 후 재작성하는 워크플로우를 제공합니다.

## 🚀 빠른 시작

### 1. 환경 준비

Python **3.10+** 권장.

```bash
# (선택) 가상환경 생성
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

### 3. 앱 실행

`spc_webapp/` 폴더로 이동 후:

```bash
streamlit run app.py
```

브라우저에서 자동으로 `http://localhost:8501` 이 열립니다.

## 📄 페이지별 기능

### 🏠 홈 — `app.py`
- 앱 소개 및 사용 가이드
- 현재 세션의 공정능력 지수(Cp / Cpk / Pp / Ppk) KPI 카드
- 종합 판정(양호 / 보통 / 부족) 신호등
- 공정능력분석 & 통계적공정관리 이론 요약 (Expander)

### 📊 공정능력분석 — `pages/1_📊_공정능력분석.py`
- **데이터 입력**: 시뮬레이션 데이터 생성 / CSV 업로드
- **데이터 탐색**: Boxplot, Histogram, 기술통계
- **정규성 검정**: Shapiro–Wilk 테스트, Q–Q Plot
- **공정능력 지수 계산**:
  - **Cp / Cpk** (군내 변동 기반, c4·d2 보정)
  - **Pp / Ppk** (전체 변동 기반)
- **Box-Cox 변환**: 비정규 데이터의 정규화 비교 시각화
- **공정능력 게이지**: 직관적인 시각화 + 자동 판정

### 📈 관리도(SPC) — `pages/2_📈_관리도.py`
- **계량형 관리도**
  - Xbar-R (부분군 ≥ 2, 소규모)
  - Xbar-S (부분군 ≥ 2, 대규모)
  - I-MR (개별값, 부분군 크기 = 1)
- **계수형 관리도**
  - NP (불량 개수, 표본크기 일정)
  - P (불량률, 표본크기 변동)
  - C (결점 수, 검사단위 일정)
  - U (단위당 결점 수, 검사단위 변동)
- **이상점(OOC) 자동 탐지**: 관리한계(UCL/LCL) 이탈 표시
- **이상치 제거 후 재작성**: 관리 이탈 부분군 제거 → 재계산

### 📋 종합 대시보드 — `pages/3_📋_종합_대시보드.py`
- 공정능력분석 + 관리도 결과를 한 화면에서 종합 모니터링
- 공정 상태 신호등 패널
- KPI 패널
- 4M(사람·기계·재료·방법) 관점 기반 **개선 권장사항** 자동 제시

## 📊 공정능력 판정 기준

| Cpk / Ppk 범위 | 판정 | 색상 | 의미 |
|---|---|---|---|
| **≥ 1.33** | 충분 | 🟢 | 공정능력이 충분 — 현 상태 유지 |
| **1.00 ~ 1.33** | 보통 | 🟡 | 3σ 수준, 개선 권장 |
| **< 1.00** | 부족 | 🔴 | 즉시 개선 조치 필요 |

## 🧪 사용 예시 (시뮬레이션 흐름)

1. `📊 공정능력분석` 페이지로 이동
2. 사이드바 → **시뮬레이션 데이터 생성** 선택
3. 변수명·목표값(target)·허용오차(tolerance)·부분군 수·부분군 크기·표준편차·평균 이동 입력
4. **데이터 생성** 버튼 클릭 → 자동으로 다음이 갱신됩니다:
   - 기술통계 / Boxplot / Histogram
   - Shapiro–Wilk 정규성 검정 + Q–Q Plot
   - Cp / Cpk / Pp / Ppk + 공정능력 게이지
5. `📈 관리도` 페이지에서 동일한 흐름으로 관리도를 생성하고 OOC 탐지 수행
6. `📋 종합 대시보드`에서 PCA + SPC 결과를 한눈에 확인

## 📚 참고 이론

- **공정능력(Process Capability)**: 공정이 관리상태에서 만족시킬 수 있는 품질 수준
- **4M**: 공정 변동의 주요 원인(사람·기계·재료·방법)
- **통계적공정관리(SPC)**: 데이터 기반으로 공정 변동을 줄이고 능력을 유지하는 통계적 기법
- **관리한계선**: `UCL = μ + 3σ`, `CL = μ`, `LCL = μ − 3σ`
- 불편화 상수: `c4`, `d2`, `d3`, `A2`, `A3`, `B3`, `B4`, `D3`, `D4` 등을 `utils/unbiased_constants.py`에서 계산/조회

자세한 설계 의도는 [`implementation_plan.md`](./implementation_plan.md)를 참고하세요.
